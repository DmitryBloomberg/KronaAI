# KronaAI — AI-ассистент в Telegram

Готовый Telegram-бот на Python: один файл `kronabot.py` содержит логику бота. Docker Compose запускает бота и Ollama; лёгкая языковая модель скачивается автоматически при первом нажатии **Start** (`/start`).

## Возможности

- Регистрация по Telegram ID, без отдельного пароля.
- Русскоязычный чат с локальной моделью Qwen 2.5 3B и сохранением истории в SQLite.
- Меню Telegram с новым диалогом, архивом, информацией о модели и удалением данных.
- Запрос таблицы → предпросмотр в чате и редактируемый файл Excel `.xlsx`.
- Запрос кода → ответ в чате и исходный файл-вложение. Код не запускается ботом.
- Запрос изображения → генерация и отправка картинки (нужен необязательный API-ключ).
- Анализ присланных фотографий (опционально, с отдельной vision-моделью Ollama).

> Это возможности Telegram Bot API, а не встроенная функция приложения Telegram. У ботов нет API для добавления произвольных нативных таблиц в интерфейс Telegram, поэтому таблица создаётся как файл Excel и показывается текстовым предпросмотром.

## Запуск

1. Установите Docker Engine и Docker Compose.
2. Создайте бота у `@BotFather` и получите токен.
3. Скопируйте `.env.example` в `.env` и впишите `TELEGRAM_BOT_TOKEN`.
4. Запустите:

   ```bash
   docker compose up --build -d
   ```

   Или запустите `./start.sh`: при первом вызове он создаст `.env` и попросит заполнить токен.
5. Откройте своего бота в Telegram и нажмите **Start**. Ollama загрузит `qwen2.5:3b` при первом запуске; это может занять несколько минут и потребует свободного места для модели.

Полезные команды:

```bash
docker compose logs -f bot       # логи бота
docker compose ps                # состояние контейнеров
docker compose down              # остановить сервисы
```

## Необязательные функции

- **Генерация картинок:** задайте `OPENAI_API_KEY` в `.env`. Генерация оплачивается по тарифу поставщика API; ключ в проект не включён.
- **Понимание фото:** задайте, например, `OLLAMA_VISION_MODEL=llava:7b`. Она будет скачана при первом анализе фото и потребует больше памяти, чем модель чата.
- **Другая модель:** задайте `OLLAMA_MODEL` в `.env`. Доступные варианты смотрите в каталоге моделей Ollama.

После изменения `.env` перезапустите бота:

```bash
docker compose up -d --force-recreate bot
```

## Архив и приватность

Профиль и переписки хранятся в именованном Docker-томе `bot_data`; веса модели — в `ollama_models`. Для удаления своих данных используйте меню бота или `/delete_me`. `docker compose down` сохраняет данные. Удаление томов необратимо:

```bash
docker compose down -v
```

Основные текстовые запросы обрабатываются локальной моделью Ollama. Для генерации изображений запрос отправляется настроенному OpenAI API. Не отправляйте боту секреты и чувствительную информацию.
